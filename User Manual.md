# User Manual



### Permissions and Passwords



##### Permissions



There are 3 types of permissions in the program: User, Manager, Admin; each one builds on the last.

&#x09; Access



Admin -   Inventory count, Inventory management, manage users.

Manager - Inventory count, Inventory management

User -    Inventory count



##### Passwords

### Main program



#### Login



To login you first have to run the file called main.py in any way you would like, as long as it stays in the folder

You will then need to input a username and password, then hit the login button (you can use the Enter key as well

for all text boxes) You can show your password with the show password button



#### Main window



##### Navigation



To navigate from one page to the next, you will need to press on the grey buttons at the top of the screen with the

name of the page you are trying to reach



##### Inventory count



This is where you input the data from the inventory counts to complete an inventory count. You count the

number of a product in stock and the name of the product in their respective entries and click the save changes

button (or press the Enter key)



##### Inventory management



###### Stock sold



This is where you input the amount of stock that was sold and where you generate reports. From here, you input the number.

and the product, and you press the Save Changes button (or press the Enter key). This has to be done before you can

create a report. Once the stock sold is done, you then can click the Generate Report button; this then puts the report

in the folder named Reports. This takes a bit of time, so don't worry if it freezes.



###### Stock purchase



This is where you input the items that have been delivered and put into the store. You input the amount purchased and

the amount that it cost to purchase, it and select a product and click the save changes button (or press the Enter key)



###### Remove product



This is where you remove a product from the database. When you do this, that product is **lost forever**. You select a

product and click the remove product button (or press the Enter key)



###### Add product



This is where you add new products. You input the barcode, name, category, cost, amount, display name and click the

save changes button (or press the Enter key)



##### manage users



###### Change permissions



This is where you change a user's permissions. You select a user and the permission that you would like them to have

and click the Save Changes button (or press the Enter key)



###### Change password



This is where you change a user's password. You select a user and the new password that you would like them to have

and click the Save Changes button (or press the Enter key)



###### Create / Remove user



This is where you create and remove users. The left side is for removing users, and you select a user and click

the Remove User button (or press the Enter key). The right side is for adding a user, and you input the user's information.

username, password, name, and their permissions and click the Remove User button (or press the Enter key)
